# 1.2.0 改修・公開確認

## 前提と実装範囲

JSONのSet IDと保存先IDを分け、修正版の再取込・セット整理で意図しない上書きや消失を防ぐ。依頼者から実装とデプロイまで指示を受けている。VercelはGitHub連携の自動デプロイを使う。

- 同じSet ID由来だけを置き換え、他セットの設問・手編集・採用選択を残す。
- IDがないJSONは入力後に取り込む。保存済みIDを参照できる。
- 無効化は別管理ファイルで行い、データは保持して編集・再有効化を許可する。
- 削除は確認付きでGitHubの保管ファイルを削除。アプリ内ごみ箱は設けず、GitHubの履歴で復元できる。使用中セットは削除・無効化できない。
- 公開用と保管用を1コミットで更新。別更新と競合したら拒否し、自動再送しない。
- 現在の独自カテゴリ・テーマでのAI生成、保存前検査、バージョン・キャッシュ更新を実装。
- JSON仕様書とサンプルを管理画面から取得できるよう公開対象へ同梱。
